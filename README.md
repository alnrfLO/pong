# 🏓 Pong

Remake du jeu **Pong** en Python avec **Pygame**, à jouer à deux sur le même clavier.

## Fonctionnalités

- Mode 2 joueurs en local
- Score affiché pour chaque joueur
- La première personne à **5 points** gagne
- Écran de victoire avec possibilité de rejouer

## Contrôles

| Action | Joueur gauche | Joueur droite |
|---|---|---|
| Monter | `W` | `↑` |
| Descendre | `S` | `↓` |

| Touche | Action |
|---|---|
| `R` | Recommencer la partie |
| `Q` | Quitter |

## Installation

```bash
pip install pygame
python Pong.py
```

## Technologies

- Python 3
- Pygame
